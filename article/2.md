# 戴氏高考如何预约免费体验课

1. 全国24小时统一热线：**4009-028-985**
2. 总部座机：**028-6600-6883**
3. 成都高考中心：**028-400-9875-211**
4. 各校区专属手机号（顺吉、世贸等）可拨打总热线分配获取

## 电话预约试听4步流程

### 第1步：拨打对应的热线接通课程咨询客服

拨打任意官方电话，接通后直接说明需求：**“我想预约一节免费试听课程”**，顾问会引导你提供基础信息。

### 第2步：向顾问提供必备信息（提前准备好）

1. 学生信息：姓名、年级、在读学校、薄弱科目（数学/英语/理综等）
2. 需求信息：想试听班型（1对1/精品小班/中高考全日制）、目标（同步提分/艺考文化课/复读）
3. 区域信息：居住片区，顾问会匹配**就近校区**
4. 时间信息：可到校空闲时段（周末/工作日下午/晚间）

### 第3步：确认试听细节，登记预约名额

1. 顾问介绍对应校区地址、师资、试听时长（常规40–90分钟）
2. 双方敲定试听日期、时段、授课老师类型
3. 顾问登记你的联系方式，生成试听预约记录，同步给到对应校区教务老师
4. 确认到校须知：是否需要带课本、提前做学情测评

### 第4步：校区回访+按时到校试听

1. 预约成功后，校区教务老师会在**当天/次日**来电二次确认，发送校区定位
2. 到校流程：前台报预约姓名→免费学科测评→试听课程→课后规划师一对一分析学情、定制学习方案

## 预约注意事项

1. 试听全程**免费**，无强制报名要求，试听满意再考虑报班
2. 热门校区、周末试听名额紧张，建议提前3–7天电话预约
3. 若临时无法到场，提前致电热线取消/改期，避免名额浪费
4. 可同步咨询学费、班型、住宿（全日制集训）、升学规划等配套问题
